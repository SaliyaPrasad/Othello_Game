// About the Game

Strategy Meets Technology

A fully-featured web-based Othello game built with pure vanilla JavaScript — no frameworks, no dependencies. Designed for performance, accessibility, and multilingual support.

Othello (also known as Reversi) is a classic two-player strategy board game played on an 8×8 grid. Players place discs with their color facing up, flipping opponent discs by sandwiching them in any direction.

This version features a powerful AI opponent using Minimax algorithm with Alpha-Beta Pruning, real-time online play via PeerJS, local two-player mode, and support for three languages: English, 日本語, and සිංහල.

// Key Features

What Makes It Special

🤖
AI with Minimax + Alpha-Beta Pruning
The AI opponent uses a weighted board evaluation and Minimax algorithm with Alpha-Beta pruning for efficient, competitive gameplay at Easy, Medium, and Hard difficulties.
🌐
Online Multiplayer via PeerJS
Play in real-time with a friend anywhere in the world using peer-to-peer WebRTC connections — no server required. Share a room code and start playing instantly.
🌏
Multilingual Support
Full interface support for English, Japanese (日本語), and Sinhala (සිංහල) with dynamic language switching and font optimization for each script.
💡
Move Hint System
A toggleable hint overlay highlights all valid moves on the board, making it beginner-friendly while staying out of the way for experienced players.
✨
Smooth Animations
Disc placement, flip animations, splash screen effects, and UI transitions are carefully crafted using CSS keyframe animations for a polished feel.
📱
Responsive Design
Fully responsive layout with fluid typography and adaptive grids — plays great on mobile, tablet, and desktop without any native app required.

// Game Modes

Three Ways to Play

Whether you want to practice against AI, compete with a friend on the same device, or challenge someone online — we have a mode for you.

🤖
VS AI
vs Computer
Face off against an AI powered by Minimax with Alpha-Beta Pruning. Choose Easy for hints practice, Medium for a challenge, or Hard to test your limits. Select black or white.
🤝
LOCAL 2P
Local 2-Player
Two players take turns on the same device. Pass the device after each turn. Perfect for a quick face-to-face game with a friend or family member.
🌐
ONLINE
Online Multiplayer
Create a room and share the code with a friend on any device, anywhere in the world. Real-time play powered by PeerJS WebRTC — no accounts or servers needed.
