// ゲーム概要

オセロとは？

AI・オンライン対戦・多言語対応を備えた本格的ウェブアプリとして生まれ変わった、8×8グリッドの古典的2人用ストラテジーボードゲームです。

オセロ（リバーシとも呼ばれる）は、8×8のグリッド上でプレイする2人用のストラテジーボードゲームです。各コマは黒面と白面を持つディスクで、プレイヤーはディスクを置いて相手のコマをひっくり返します。

手を打てるのは、縦・横・斜めのいずれかの方向で相手のディスクを1枚以上挟むことができる場所だけです。挟まれたディスクはすべて自分の色に反転されます。

どちらのプレイヤーも手を打てなくなった時点でゲーム終了です。ボード上のディスクが多いプレイヤーが勝者となります。四隅は最も重要なマスで、一度取られると絶対にひっくり返せません。

ルールの説明

⚫ 基本ルール

  1. ゲーム開始時、盤面中央に黒2枚・白2枚が配置されます。
  2. 常に黒が先手です。
  3. 有効な手は、任意の方向で相手のディスクを1枚以上挟む必要があります。
  4. 挟まれたディスクはすべて自分の色に反転されます。
  5. 有効な手がない場合、そのターンはスキップされます。
  6. どちらも手を打てなくなるか、盤面が埋まったらゲーム終了です。
  7. ディスクが多いプレイヤーが勝利します。

♟ 戦略のコツ

  • 四隅（価値：100）は最強のマスで、一度取ると絶対にひっくり返されません。
  • 辺は反転方向が限られるため有利な位置です。
  • Xマス（四隅の斜め隣）を避ける — そこに置くと相手に四隅を取られてしまいます。
  • 手数が重要：有効な手が多いほど相手の選択肢を制限できます。
  • パリティ：あるエリアの最後の手を打てることが有利になります。
  • 序盤はディスク数を少なく保つことを目指しましょう — 相手の手を減らせます。
// 遊び方

はじめ方

ゲームを起動して、以下の手順でどのモードでもプレイを開始できます。

01
言語を選ぶ
起動時はデフォルトで日本語が選択されています。右上の言語スイッチャーを使って英語またはシンハラ語（සිංහල）に切り替えられます。
02
ゲームモードを選ぶ
メインメニューから選択：VS AIでコンピュータ対戦、ローカル2Pで同じデバイスで対戦、オンラインで友達とリモート対戦。
03
設定を変更する
VS AIモードでは難易度（かんたん・ふつう・むずかしい）を選び、黒（先手）か白（後手）かを選択します。
04
ニューゲームをクリック
ニューゲームボタンを押してスタート。盤面中央に4枚のディスクが配置されます。緑の点（ヒント）が置ける場所を示します。
05
手を打つ
ハイライトされたマスをクリックしてディスクを置きます。挟まれた相手のディスクがなめらかなアニメーションと効果音とともにすべてひっくり返ります。
06
ゲーム終了
打てる手がなくなると、結果モーダルに最終スコアと勝者が表示されます。もう一度で再戦、メニューでモード選択に戻れます。

// AIエンジン

AIの仕組み

AIは古典的なミニマックスアルゴリズム（アルファベータ枝刈り付き）を使用しています。これはゲームツリーを探索し、考えられるすべての将来の局面を評価して、自分の優位性を最大化しつつ相手の優位性を最小化する手を選ぶ手法です。

アルファベータ枝刈りは結果に影響しないゲームツリーの枝を除外し、計算量を大幅に削減することでより深い探索（むずかしい難易度では深さ5まで）を可能にします。

各盤面は重み付きポジションテーブルと手数ボーナスを組み合わせて評価されます。相手より多くの有効手を持つほど有利になります。テーブルでは四隅（100）に高い価値、Xマス（−50）に負の値、内側のマスには中立の値が割り当てられています。

// オンラインアーキテクチャ

オンライン対戦の仕組み

リアルタイムマルチプレイヤーはFirebase Realtime Databaseによるシグナリングとルーム管理で実現しており、専用ゲームサーバーは不要です。

ホストの流れ

1

ルームコード生成

一意の5文字英数字コード（例：X7K2P）が生成され、Firebase の /rooms/[code] に書き込まれます。

2

ゲストを待つ

Firebase SSE（Server-Sent Events）がルームノードを監視します。ゲストが参加すると guest フィールドがリアルタイムに更新されます。

3

ゲーム開始

両プレイヤーが接続されると、ホストが status: "ready" をパッチし、両サイドがSSEトリガーで同時にゲームを開始します。

4

手の同期

各手はタイムスタンプとプレイヤーロールとともに /rooms/[code]/moves にプッシュされ、相手がSSE経由で受信して適用します。

ゲストの流れ

1

ルームコード入力

ホストから共有された5文字コードを入力します。アプリが /rooms/[code] を取得してルームの存在と空き状況を確認します。

2

ゲストとして登録

ゲストが自分の名前をルームノードにパッチします。これにより即座にホストのSSEリスナーがトリガーされ、到着が通知されます。

3

ゲーム開始

ゲストはSSEで status: "ready" を監視します。検出されるとゲーム画面が表示され、両プレイヤーがライブ状態になります。

4

重複排除

すべての手のメッセージにはタイムスタンプが含まれます。クライアントは最後に処理したタイムスタンプを追跡し、再接続時の二重適用を防ぎます。
